# Signals and Telemetry

AI4I-Observe captures multiple categories of signals:

* Structured logs (inference, gateway, system)
* System metrics (CPU/GPU, memory, storage, network)
* API metrics (latency, throughput, error rates)
* Model quality metrics (BLEU, WER, CER, toxicity, hallucination)
* Business and adoption metrics
* User and governance feedback signals
